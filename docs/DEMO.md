# Guion de demostración

1. Abre la landing y muestra que el proyecto es responsive e instalable.
2. Entra como entrenador demo para revisar métricas, alumnos y rutinas.
3. Crea una rutina desde la biblioteca.
4. Entra como alumno demo y abre el entrenamiento del día.
5. Registra peso y repeticiones, completa un set y finaliza la sesión.
6. Abre Progreso para comprobar el volumen y el nuevo récord personal.
7. Muestra Swagger en `/api/docs`, el health check en `/health` y los tests del repositorio.

Todos los nombres y datos del seed son ficticios. La demo no debe almacenar información médica o de pago real.
